学习用二次认证 Demo

页面只负责调用控制器接口（Auth / TwoFactor / Profile），不在前端伪造登录态。

推荐流程

  1. 注册账号（可填邮箱/手机，便于勾选 Sms/Email 位）
  2. 登录拿到 access_token
  3. 在「管理 2FA」绑定 Authenticator，设置 Methods（如 7）
  4. 退出后再登录 → 进入「二次认证」页选 provider

页面入口

  • 注册POST /api/register
  • 登录POST /api/login → token 或 mfa_ticket
  • 二次认证POST /api/login/2fa | /api/login/recovery
  • 管理 2FAsetup / enable / methods / me

位标志速查

Authenticator = 1 Sms = 2 Email = 4 全选 = 7

登录返回的 providers = TwoFactorMethods ∩ 实际可用（有密钥 / 手机已确认 / 邮箱已确认）。
